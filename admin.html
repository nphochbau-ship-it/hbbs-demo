Einmalige Einrichtung

Gerät verbinden.

Damit Änderungen für alle Besucher sichtbar werden, braucht dieses Gerät einmalig einen GitHub-Zugangsschlüssel (Token). Er wird nur auf diesem Gerät gespeichert.

So erstellen Sie den Token

  1. Öffnen: github.com/settings/personal-access-tokens/new (als nphochbau-ship-it angemeldet)
  2. Name: HBBS Admin, Ablauf: z. B. 1 Jahr
  3. Repository access: Only select repositories → hbbs-demo
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, kopieren und oben einfügen.
